# 신해달 가상 갤러리: 내부 공간 자문 브리프

## 작가와 갤러리
- 신해달: 나전칠기(검은 옻칠 + 자개) 작가. 대표 IP 캐릭터 「얼빵해달」(흰·연하늘 털, 파란 물방울 눈, 파란 마름모 코, 분홍 볼). 법과 권리(저작권·권리소진 등)를 작품 주제로 다루고, 팝아트·우주·「N차적 저작물」 같은 개념 연작이 있다. 그림책 「해달도 배워야 수영을 한다」, 캐릭터 그룹 「일월오봉단」(일월오봉도에서 출발: 학·토끼·호랑이·사슴·해달).
- 웹 브라우저에서 도는 3D 가상 갤러리(three.js). 컴퓨터와 휴대폰. 관람객은 화면에 보이지 않고 발밑에 선한백호 발자국만 찍힌다. 바닥을 눌러 걷고, 작품을 누르면 정보 패널이 뜬다. 도장(조개) 5개를 모으면 마지막 라운지에서 이름을 넣은 멤버십 카드를 받는다.
- 외관(현재 시안): 유럽 숲속, 북쪽으로 오르는 단(4단)에 회색 대리석의 미니멀한 박공 덩어리들. 지붕들이 가운데로 겹겹이 솟아 일월오봉도의 봉우리를 추상화. 둘레는 대리석 광장과 등받이 없는 나무 벤치.

## 확정된 배치(평면)
- 남쪽에서: 로비 → 작가소개 → 작품관(2×2 한 바퀴) → 중정 → IP 체험관(2×2 한 바퀴) → 중정 → 일월오봉단관(가장 높은 주봉, 북쪽 맨 위) → 해달 라운지(출구).
- 중정을 가운데 두고 두 관이 날개처럼 좌우로. 관마다 방 4개(약 14 × 11 m)를 2×2로 묶어 한 바퀴 돌면 들어온 문 옆으로 나온다. 늘릴 때는 2×3.
- 중정에서 각 관으로 드는 입구·출구는 불투명 유리문. 작품관 방 사이는 문 없이 조명을 낮춘 꺾인 통로(2.4 m 폭), 꺾이는 벽에 다음 섹션 이름과 소개.

## 작품관 네 섹션(순서 확정) — 작품은 모두 작고, 시리즈는 앞으로 늘어난다
1. 법과 권리: 흰 벽, 작품만. 더 블루북(A1), 헌법 제10조 행복추구권(31.8cm), 이 세계의 얼빵해달 저작인접권자가 되었다!(45cm), 안녕! 권리소진의 원칙(27.3cm), 권리누적: 이차원에서 삼차원으로(15cm), 조개배달부 얼빵해달 2026 한정판(입체 10×9×6cm).
2. POV(팝아트): 워홀 노랑 바탕에 분홍 조개 무늬 벽지, 은박 말풍선이 공중에 둥둥(Silver Clouds), 들어오는 통로 벽에 리히텐슈타인 점. 출근(20cm), 업무 중(53cm), 퇴근(20cm), 유급휴일(27cm). 통로 벽에는 순서를 쓰지 않는다(작품이 늘어남).
3. 우주조약: 깊은 우주 배경, 팔각 창살, 검은 바닥, 문구 없음. 우주조약(37.9cm), 무주의 바다(38cm).
4. N차적 저작물: 사유의 방처럼 어둠 속 부드러운 빛, 실제 크기 비율. N차적 저작물A·B(27.3cm), nn차적 저작물a(15cm).
- 모든 작품에 오른쪽 아래 캡션. 작품관 전체는 진중하고 깊이 있게.

## IP 체험관 네 장면(미니게임은 아주 쉽게)
해변(얕은 물, 조개 3개 줍기) → 숲길(통창 옆 쉬운 나무 미로, 막다른 곳마다 작은 발견) → 작업실(작가에게 조개를 건네 옻칠판 빈자리에 붙이기) → 수영장(그림책 7p: 화려한 수영복 고급반, 단색 초급반, 해달은 초급반으로; 게임은 미정). 소리는 브라우저에서 만든다.

## 일월오봉단관 · 해달 라운지
- 일월오봉단관: 일월오봉도 벽 앞 두 단 단상에 캐릭터 다섯, 사유의 방처럼 어두운 방.
- 해달 라운지: 이름 이야기(얼빵 → SPACED-OUT, 해달 → SUN + MOON), 늘어날 수 있는 아트토이 진열장, 멤버십 카드 키오스크, 해달자개 브랜드샵 안내.
