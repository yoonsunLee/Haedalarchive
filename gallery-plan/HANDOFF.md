# 신해달 3D 갤러리 작업 인계 (2026-11-05)

다른 Claude 계정으로 같은 컴퓨터에서 이어 작업할 때 이 문서부터 읽는다. 작업 방식 규칙은 저장소 맨 위 `CLAUDE.md`에 있다.

## 1. 무엇을 하고 있나

- **대상:** 나전칠기 작가 신해달(IP 캐릭터 얼빵해달)의 three.js 가상 갤러리. 결과물은 `gallery/index.html` 한 장이다.
- **방식:** 컨셉 보드(`gallery-plan/concept.html`)에서 작가님이 공간마다 하나씩 정한 내용을 실제 갤러리에 한 공간씩 반영한다.
- **기준:** 바탕은 버전 31 갤러리다. 외관 모양은 바꾸지 않고 다듬는다.

## 2. 공간별 진행 상황

정한 순서는 외관 → 로비·작가소개 → 작품관(+다섯 문턱) → 중정 → 일월오봉단관 → 해달 라운지 → IP관 → 빛 굽기(맨 끝)이다. 작품관은 작가님이 건너뛰고 중정으로 가자고 해서 뒤로 미뤘다.

끝(x −34.0 ~ −31.6)에 룸3 문. 문턱③: 북 → 서 → 북 약 14 m(폭 2.6, 천장 2.8), 벽빛 노랑 → 먹회색, 바닥 테라초 → 어두운 테라초 → 젖은 돌, 글 없음(작가님 결정), 도시 소음은 첫 꺾임에서 끊기고 물결 소리. 룸3 우주조약: 가운데 (−38.8, −24.8), 폭 10 m 팔각, 천장 5 m, 먹회색 벽. 남쪽 면 **IP관 새 원칙(작가님 결정, 2026-11-06):** 가상공간이라 장면을 실제 길로 다 잇지 않는다. 장면(해변·숲길·작업실·수영장)은 떨어진 섬, 장면 사이는 짧은 전환(통로 3~6 m 또는 문)이고 통로 끝 문과 다음 장면 첫 문을 똑같이 만들어 문을 지나는 순간 관람객 자리를 옮겨 이어 붙인다(화면 전환 효과 없음). 실제로 걸어 이어지는 곳은 중정 → ① 물빛 → 해변뿐. IP관 출구는 중정이 아니라 해달 라운지(수영장 → ⑤ 물자국 → 라운지). 중정 동쪽 벽 "IP관 나가는 곳" 문(patch-doors.py autoDoor z 10.4, 4.2~6.8)은 없애거나 막을 것. 장면이 겹쳐 있어도 되도록 showInteriors는 지금 장면과 이어 붙는 이웃만 보이게 고쳐야 함. 전문가 동선안(② 길 1.6 m 옮기기)은 쓰지 않음. 작품관은 그대로(실제로 이어진 방과 문턱), 방을 늘릴 때만 섬 + 이어 붙이기를 쓴다(작가님 결정).

**② 그림자 줄 길 반영(g8-ip.js `ipPath2`, `P2`):** 해변 숲 쪽 문을 x 21 → 23으로 옮김(라운지 건물 x 21과 겹침). 문은 A안(작가님 결정): 하얀 문틀 + 세로 나무 살 문짝이 서쪽으로 미끄러져 열림(셋 다 주운 뒤, `BEACH.gateK`). 문 둘레는 덤불 띠 한 장(폭 8 m)에 문 모양만 뚫음(`exitBand`). 문 너머는 처음 만든 하얀 실내 복도 대신 나무 사이 그늘길(작가님 결정, 전문가 셋 자문 + 두 샘플 비교 뒤): 길 x 22~24, z 5.2~12.1, 양옆 Lathe 줄기(`TR`), 잎 지붕 높이 `CAN` 3.9. 그림자 줄은 셰이더 `sunLit()`(서쪽 줄기 줄에 해 방향을 투사, 잎 지붕 볕은 노이즈), 바닥 모래 → 데크 → 흙, 둘레 하늘 상자 `PS`(x 21.15~31, 라운지에 닿지 않게)는 z로 한낮 → 노을. 해변 하늘 상자 SB는 길 자리(y < 6.3)를 discard, 해변 숲 띠는 길 위에서 걷어 냄. 끝은 저녁 숲 띠로 열려 있되 z 12.1에서 막힘(숲길 만들 때 풀기). 소리: 파도 → 풀벌레. 오르막은 아직 평평. 시트 img/ip-passage2-step2.jpg, img/ip-passage2-gate.jpg. 작가님 확인 대기.

  - 시점: aerial, court, obong, front, far, mid, near. 쉼표로 여러 개를 주면 장면을 한 번만 불러 차례로 찍는다.

  - 굽는 UV 맵을 물체의 활성(active, active_render) UV로 해야 한다.
