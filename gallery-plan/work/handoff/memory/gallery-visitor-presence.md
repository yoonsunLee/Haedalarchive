The visitor in the 3D gallery is invisible: walking leaves paw footprints (patch-paws.py hides the avatar). The footprints are the same everywhere, IP zone included (user, 2026-11-05). Visitors cannot tell whose footprints they are; 선한백호 was only an example the user gave, so never label or change them per zone.

In the IP관 the visitor becomes 얼빵해달 and experiences that world. There is still no visible body, so minigame feedback must come through footprints, camera and the surroundings, never avatar gestures (lying down, jumping, nodding).

**Why:** I once briefed experts that the visitor walks as a third-person otter avatar, and later proposed switching to otter footprints in the IP zone; the user corrected both.
**How to apply:** state this premise in any brief or proposal about scenes, transitions or minigames. Related: [[gallery-v31-preferred]], [[gallery-3d-pipeline]].
