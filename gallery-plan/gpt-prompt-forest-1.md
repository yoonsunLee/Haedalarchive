## 이 프로젝트
- 갤러리 안 'IP관'은 작가의 캐릭터 '얼빵해달'의 하루를 관람객이 직접 걸으며 겪는 공간이야.
- 얼빵해달은 **현대사회에 사는 조개배달부**야. 전통 소재나 동화 속 세계가 아니라 지금의 일상이야. 작가님의 색연필 그림은 '그림체'일 뿐이니, 종이·한지·책 같은 재료 느낌은 넣지 마.
- 장면 순서: 해변(한낮) → 나무 사이 그늘길(해가 기욺) → **숲길(해 질 녘)** → 작업실(밤) → 수영장(다음 날 아침).
- 이번에 만드는 곳은 **숲길**이야.
  - 해 질 녘, 키 큰 나무와 덤불로 된 가벼운 미로야. 1~2분이면 빠져나와.
  - 걷는 길 폭은 1.5~2 m이고, 덤불 벽은 눈높이보다 높은 약 2.6 m야. 벽 위로 노을 하늘과 나무 머리가 보여.
  - 해는 서쪽에 낮게 떠 있어.
  - 막다른 곳 셋에는 '일월오봉단' 친구들의 물건이 하나씩 놓여 있어. 친구들은 나오지 않고 물건만 있어서, 누구 것인지 맞혀 보는 재미가 있어.
- 화면은 웹 브라우저(three.js)가 실시간으로 그려. 조명을 계산하지 않는 재질이라, 그림 속 색과 명암이 그대로 화면에 나와.
- 작가님 그림을 잘라 쓰지 않고, 그 그림체로 새로 그린 그림만 써.

## 꼭 먼저 볼 것

2. 이미 만들어 실제로 쓰고 있는 애셋. 이것들과 색·결·밝기를 맞춰 줘. 특히 해 질 녘 판 두 장이 숲길 색의 기준이야.

   - `gallery/ip/new/beach/leaf.png`, `gallery/ip/new/beach/bark.png`, `gallery/ip/new/beach/sand.png`
3. 일월오봉단 친구들(색과 성격 참고만 해. 그림에 친구들을 넣지는 마)
   - `gallery/img/deer-cutout.webp`: 솔직사슴(나무꾼, 소나무)
   - `gallery/img/rabbit-cutout.webp`: 정월토끼(신분을 숨긴 공주, 달)

4. 실제 화면: `gallery-plan/img/ip-beach-assets-test3.jpg`. 아래 두 칸이 숲길로 들어가기 직전의 그늘길이야. 바닥의 나무 데크와 해 질 녘 숲 띠가 보여.

## 모든 그림에 공통
- 따뜻한 크림색 바탕에 그린 색연필 그림책 그림 결이야. 색연필 결이 살짝 보이고, 부드럽게 그려 줘.
- 모양은 둥글고 보송하게, 곧은 모서리는 피해 줘.
- 검은 윤곽선은 물건(4~6번)에만 가늘고 살짝 떨리게 넣어 줘. 바닥과 덤불 같은 넓은 면에는 선을 넣지 마.
- 사람, 캐릭터, 동물, 글자, 숫자, 로고는 넣지 마.
- 작가님 그림을 베끼지 말고, 같은 손으로 새로 그린 것처럼 그려 줘.
- 파일은 PNG(sRGB)야.
  - '투명'이라고 적은 것은 배경이 투명해야 하고, 가장자리에 흰 테두리(헤일로)가 없어야 해. 물건은 투명 여백을 사방 16 px 이상 둬.
  - '이어 붙는 결'은 적힌 방향의 가장자리가 끊김 없이 이어져야 하고, 밝기가 고르게(한쪽만 밝거나 어둡지 않게) 그려야 해.
