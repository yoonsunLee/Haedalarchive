# 문의 접수 (국내 웹호스팅용)

홈페이지 Contact 폼을 **국내에서만** 처리하는 접수 스크립트입니다. 문의를 저장하지 않고 작가 메일함으로만 보냅니다.

- `contact.php` — 접수 본체 (PHP 7.0 이상, cURL 필요)
- `config.sample.php` — 설정 예시. `config.php`로 복사해 값을 채운다(저장소에 올리지 않음)
- `.htaccess` — 설정 파일과 반복 접수 기록 폴더를 웹에서 못 열게 막음

## 왜 이 구성인가

네이버 클라우드 Cloud Functions는 한국 리전이 VPC 전용이라, 외부 호출을 받으려면 NAT Gateway(월 고정비가 큰 항목)가 필요했습니다.
문의 폼 하나를 위해 쓰기에는 과해서, 국내 웹호스팅에 파일 하나를 올리는 방식으로 바꿨습니다.
메일 발송은 도메인 인증을 마친 **네이버 클라우드 SENS Mail API**를 그대로 씁니다.

| | 이전 (2026-09) | 지금 |
|---|---|---|
| 접수·저장 | Supabase(서울 저장, 미국 법인) | 국내 웹호스팅, **저장 안 함** |
| 알림 메일 | Resend (미국) | 네이버 클라우드 메일 API (한국) |
| 스팸 방지 | Cloudflare Turnstile (미국) | 서버 검증 여러 겹 |
| 수신함 | contact@ → Cloudflare 전달 → 네이버 | 작가 네이버 주소 직접 |

→ 문의 폼에서 **국외 이전 동의를 받지 않아도 되는 구조**입니다(수집·이용 동의만 유지).
남는 국외 요소는 홈페이지 호스팅(GitHub Pages)의 접속 기록뿐이며, 문의 내용과 분리해 처리방침에 고지합니다.

## 설치

1. 호스팅 신청 후 **서브도메인**(예: `api.shinhaedal.com`)을 호스팅에 연결하고 무료 SSL 신청
   - Cloudflare DNS에 호스팅이 안내하는 A 레코드(또는 CNAME) 추가, 프록시는 **DNS 전용**
2. `config.sample.php`를 복사해 `config.php`를 만들고 값 채우기
3. FTP로 `contact.php`, `config.php`, `.htaccess` 업로드 (웹 루트 또는 하위 폴더)
4. 확인
   ```bash
   curl -i -H "Origin: https://shinhaedal.com" "https://api.shinhaedal.com/contact.php?op=token"
   ```
   `{"t":...,"n":"...","s":"..."}` 가 나오면 정상
5. 사이트 폼의 `CONTACT_API` 를 이 주소로 바꾸고 배포

## 스팸 방지 구성

| 겹 | 막는 것 | 한계 |
|---|---|---|
| 허니팟(숨은 칸) | 폼을 그대로 채우는 단순 봇 | 사람이 우회하면 무력 |
| 제출 토큰(GET `?op=token`) | 폼을 열지 않고 바로 POST하는 봇. 발급받은 접속과 IP가 다르면 거부 | 브라우저를 흉내내면 우회 가능 |
| 같은 내용 연속 차단 | 같은 문의 반복 발송 | 내용을 조금씩 바꾸면 우회 |
| IP별 10분 3건 | 한 곳에서 몰아 보내기 | 파일로 세므로 호스팅 용량만큼만 |
| 길이·형식 검증 | 비정상적으로 큰 요청, 잘못된 입력 | — |

CAPTCHA와 같은 수준의 차단은 아닙니다. 실제 스팸이 들어오면 그때 강화합니다.

반복 접수 기록(`_rate/`)에는 **되돌릴 수 없는 해시값과 시각만** 남고 10~20분 뒤 지워집니다. 문의 내용·연락처는 어디에도 저장하지 않습니다.

## 전환 순서

1. 호스팅에 올려 접수·수신 확인 (시험용 주소로)
2. 처리방침 **변경 예고** 게시 (시행 7일 전 — 현행 처리방침 14항의 약속)
3. 시행일에 사이트 폼 전환 + 처리방침 개정판 적용
4. 전환 확인 후 정리: Supabase `contact` 함수와 `inquiries` 관련 표, Turnstile 위젯,
   Cloudflare Email Routing(contact@)과 관련 DNS 레코드
