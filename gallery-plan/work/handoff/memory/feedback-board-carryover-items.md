Some lines on the concept board came over from the deleted 설계안 artifact when the two boards were merged. The user never chose those lines item by item. Examples are the 중정 "현대적 해석" line: pine and crape-myrtle planters, black stone basin, glass railing.

When I built the 중정 (2026-11-05), the user removed the crape myrtle and the basin. They rejected the glass railing outright: "하라고 한 적도 없는 거구만".

**Why:** the user decides every item personally ([[feedback-dont-repeat-dismissed-points]]). A carried-over line is not their decision.
**How to apply:** before building a space, separate the board lines the user explicitly chose in conversation from the carried-over ones. Build only the chosen ones. List the carried-over ones and ask before adding them. Related: [[feedback-one-space-at-a-time]].
