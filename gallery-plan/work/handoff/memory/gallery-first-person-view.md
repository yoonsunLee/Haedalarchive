The 3D gallery now views from first-person eye height (1.55 m, FOV 70° PC / 75° mobile). The old 3rd-person camera 3.4 m behind is gone. Wheel/pinch only narrows the FOV; it never pulls back. Decided 2026-11-06 after the user found the camera sticking to hedges and rising above the maze.

**Why:** the visitor has no visible body, only footprints ([[gallery-visitor-presence]]), so a camera behind an invisible body made little sense. It also fixes the "spaces feel narrow" complaint.

**How to apply:** the user said "try it; I'll say if I dislike it". So it is not final. Shoot screenshots and plan spaces for eye-level first person. Keep the camera from seeing over maze walls.
