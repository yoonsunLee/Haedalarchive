# IP관 ② 해변 애셋 용도표 (Claude 쪽 작업 기준)

GPT가 해변 애셋 명세를 만들 때 맞출 기준이에요. 기존 시점, 눈높이, 장면 순서는 그대로 두고, 문턱(①)은 보류해요.

## 0. 먼저 알아 둘 것: 화면을 그리는 곳

- **최종 화면은 Blender 렌더가 아니에요.** 웹 브라우저(three.js)가 실시간으로 그려요. 휴대폰에서도 열려요.
- **Blender의 역할**
  - 입체 물체(나무, 문틀 등)를 만들어 웹용 3D 파일(glTF)로 내보내요.
  - 다른 관에서는 빛을 구워 넣는 데도 써요.
- **IP관에는 조명이 없어요.**
  - 그림책 느낌을 내려고 빛을 계산하지 않는 재질을 써요.
  - 그래서 그림에 그려 넣은 색과 명암이 화면에 그대로 나와요.
  - 은은한 그늘이 필요하면 그림 안에 그려 넣어야 해요(그림자는 거의 없이).
- **"실제 적용 화면"은 갤러리를 직접 띄워 찍은 사진이에요.** 지금까지처럼 헤드리스 Chrome으로 찍어 보여 드려요.

## 3. 모든 애셋 공통 규격

- **색:** sRGB PNG. 「줍기」의 색이 기준(모래 노랑, 바다 옥색·하늘색, 조개 산호 분홍).
- **빛:** 조명을 계산하지 않으니, 그림 안의 명암이 곧 화면 명암이에요. 위에서 고르게 비춘 밝은 낮빛으로 그리고, 한쪽으로 쏠린 그림자는 넣지 마세요.
- **잉크 윤곽:** 조개, 조약돌처럼 알아봐야 할 물건에만. 모래, 물, 숲 덩어리에는 선을 넣지 마세요.
- **투명 PNG**
  - 가장자리에 흰 테두리(헤일로)가 남지 않게 해 주세요.
  - 투명 여백은 사방 16 px 이상 두세요.
  - 기준점: 바닥에 눕히는 것(조개·조약돌)은 그림 한가운데, 세우는 것(숲 줄기)은 아래 가장자리 가운데예요.
- **이어 붙는 결**
  - 위아래, 좌우 가장자리가 끊김 없이 이어져야 해요. '가로로만'이라고 적은 것은 좌우만 이어지면 돼요.
  - 밝기가 한쪽으로 쏠리지 않게 해 주세요.
- **크기:** 적힌 크기 이상이면 돼요. 웹에서 가볍게 쓰도록 Claude가 WebP로 바꾸고 줄여요.
